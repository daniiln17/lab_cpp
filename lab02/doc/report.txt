C++ и Python: сравнение производительности

1. C++ программа
   Файл: lab02/src/main.cpp
   Компиляция: g++ -O2 ../src/main.cpp -o lab02_cpp -lm

2. Python программа
   Файл: lab02/src/main.py
   Запуск: python3 ../src/main.py

3. Сравнение времени выполнения
   | n          | C++ (мс) | Python (мс) |
   |------------|----------|-------------|
   | 100 000    | ...      | ...         |
   | 1 000 000  | ...      | ...         |
   | 10 000 000 | ...      | ...         |
   | 100 000 000| ...      | ...         |

4. Вывод
   Python работает медленнее, т.к. интерпретируемый.
   C++ работает быстрее, т.к. компилируемый.
